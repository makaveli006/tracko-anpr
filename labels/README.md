# Hand-labelled ground truth for measuring accuracy

The procedure, the columns and the labelling rules are in `ARCHITECTURE.md`, section "HOW TO MEASURE REAL ACCURACY", and the first result is under "FIRST ACCURACY MEASUREMENT". `zoomed-in` is labelled: all 59 tracks read by Claude from the crops, 21 of them also read blind by the user. Recount with `uv run python tools/measure_accuracy.py labels/zoomed-in_system.csv labels/zoomed-in_truth.csv`. Files go here as `<video>_system.csv` (the export of the system's answers) and `<video>_truth.csv` (the hand labels). Keep them in git so the measurement can be repeated after any change to the pipeline.
